# 디자인 적용
해석: 혼자 사는 20~30대 여성이 같은 동네 이웃에게 묻고 답을 다시 찾는 지역 커뮤니티 웹, 데스크톱 1440과 모바일 393. 다이얼 V6/M5/D5.

## 채택 (UUPM)
- 스타일: Minimalism. 커뮤니티는 글이 주인공이라 장식이 적은 쪽
- 컬러: 위치를 뜻하는 초록 #047857과 행동 주황 #C2410C의 2색 체계(UUPM Location green + action orange). 글자용 초록은 대비를 위해 한 단계 진하게 보정
- 디스플레이 폰트: Outfit(자동 교체, 원래 추천 Inter는 금지 목록). 로고와 숫자에만, 한글 제목은 Pretendard

## 버림
- override의 "버린 것" 전부
- 민트 전체 배경: 차분한 톤 요구와 헬스 앱 인상 때문에 옅은 올리브 회색으로 교체
- 분홍, 하트, 파스텔 그라데이션: spec이 금지
- Hero, 회원 수 같은 검증 불가 수치, 가입 CTA: 서비스 화면이고 목업에 근거 데이터가 없음

## 아트 디렉션
무드: 따뜻한, 수다스러운, 동네 잡지 같은
레퍼런스:
- 당근 동네생활(실측): 동네 인증을 작성자 줄에 붙이고, 목록 행은 칩을 최소로 두어 제목과 한 줄 본문이 먼저 읽힘
- 오늘의집 커뮤니티(실측, 사용자 제공 캡처): 사진 글을 가로 카드 띠로 먼저 보여 줌(카드 폭 약 310px, 제목 2줄, 63px 정사각 썸네일 4개에 "+11" 오버레이, 작성자와 조회, 댓글 수). 필터는 알약 칩에 선택 시 검은 배경. 피드는 폭 약 750px 가운데 정렬, 우측 사이드 없음, 글마다 회색 소형 카테고리 라벨, 굵은 제목 약 18px, 본문 2줄, 메타 한 줄, 우측 약 100px 라운드 썸네일
- 29CM 매거진(다른 업종, 미확인): 섹션 제목을 크게, 목록 본문을 작게 해 크기 대비로 위계를 만듦
한글 디스플레이: Hahmlet Variable
시그니처:
- 워드마크: 지붕 선이 모자처럼 얹힌 'ㅎ' SVG 마크 + "혼집" 글자. 상단 바에 항상 보임
- 큰 색 면: 홈 상단에 초록 브랜드 영역(면적 15% 이상). 큰 슬로건과 창문 격자 모티프
- 창문 격자 모티프: 브랜드 영역 배경, 사진 자리, 빈 상태에 같은 2x2 창문 그래픽을 반복
- 공감 피드백: 누르면 엄지가 한 번 튀고 숫자가 바뀌는 즉시 피드백(reduced-motion이면 즉시)

## 구조 변경
- 우측 사이드에 안전 알림과 주제별 이야기 두 카드를 구성해 빈 공간을 해소
- 채택 답변이 달린 글을 가로 카드 띠로 먼저 보여 주고 나머지는 행으로 둠(같은 모양 반복 해소)
- 주제 필터를 밑줄 탭에서 알약 칩으로 변경
- 배너를 글자 배너에서 제목과 건물 일러스트가 맞물리는 구성으로 변경

## 더한 것
- 지붕 'ㅎ' 워드마크: 글자뿐이던 로고를 형태 있는 마크로
- 홈 상단 초록 브랜드 영역: 브랜드 색이 버튼에만 있던 문제를 해결(면적 확보)
- 창문 격자 모티프: 기본 이미지 아이콘 대신 서비스 고유의 사진 자리와 빈 상태 그래픽
- 많이 본 글: 1~3위를 같은 크기와 글꼴로 나열(1위만 강조하면 어색해서 되돌림). 반복을 깨는 역할은 가로 카드 띠가 맡음
- 목록 행 칩 축소: 항목당 주제 + 상태 하나만, 채택 답변 박스는 상세로 이동
- 공감 마이크로 인터랙션

## 앞선 프로젝트와 다르게 고른 것
- 셸: 상단 바 + 반응형 햄버거(앞선 partloop 계열은 모두 좌측 레일)
- 레이아웃: 카드 격자 대신 구분선 목록 행, 사이드는 우측 고정 박스
- 폰트: Outfit(partloop 계열은 Plus Jakarta Sans), 본문 15~16px
- 모션: 공감 숫자 즉시 교체와 200ms 페이드뿐

## 2차 수정 (레퍼런스 실측 반영)
확인한 화면: 당근 동네생활 검색 결과(실측), 브런치 홈(실측). 오늘의집은 브라우저 권한 문제로 열리지 않아 사용자가 캡처를 제공함(실측). 29CM 매거진은 열리지 않아 확인 못 함(기억 기반이므로 참고만).
- 오늘의집에서 반영한 것: 알약 필터(선택 시 검은 배경), "이웃이 답해 준 질문" 가로 카드 띠. 우측 사이드 없는 단일 열은 시도해 보았으나 사용자 판단으로 되돌림(참고하되 따라 하지 않음, 우측 사이드 유지)
- 당근에서 가져온 것: 목록 행에서 본문 한 줄, 메타는 작은 회색 한 줄, 썸네일은 우측 작은 라운드 사각. 그래서 행 본문을 2줄에서 1줄로 줄임
- 브런치에서 가져온 것: 한글 세리프 제목과 큰 제목 크기 대비, 넉넉한 여백. 그래서 한글 제목에 Hahmlet(현대적 세리프) 도입, 배너 제목 44px
- 한글 디스플레이 폰트: Hahmlet Variable (`@fontsource-variable/hahmlet`). 로고, 배너, 섹션 제목, 사이드 카드 제목, 글 상세 제목. 본문과 라벨은 Pretendard 유지
- 글꼴 규칙: 세리프(Hahmlet)는 로고, 배너, 페이지와 섹션과 사이드 카드 제목에만. 목록 안의 글 제목(많이 본 글, 답해 준 질문 카드, 글 행)은 모두 Pretendard 굵게로 통일
- 배경: 차가운 회녹색에서 따뜻한 크림(#FAF5EA)으로. 선, 면, 글자색도 따뜻한 갈색 계열로 통일 (무드 "따뜻한")
- 창문 모티프 재설계: 잘린 톤온톤 사각형 대신 건물 일러스트(Facade). 불 켜진 창(주황)은 답해 주는 이웃, 말풍선이 걸린 창은 대화 중. 사진 자리는 불 켜진 창 하나가 있는 따뜻한 타일
- 홈 구조(3차): 좌측 본문은 배너, 많이 본 글, "이웃이 답해 준 질문" 가로 카드 띠(채택 답변이 있는 글, 카드 286px), 알약 주제 필터, 글 행. 우측 사이드(안전 알림, 주제별 이야기)는 유지. 같은 모양 반복을 가로 카드 띠로 깸
- 배너에 "궁금한 것 물어보기" CTA 추가(데스크톱)

## 사진 요청
- 사진이 있는 글(곰팡이, 택배함, 식재료 나눔, 환기)의 썸네일과 "이웃이 답해 준 질문" 카드의 63px 정사각 썸네일: 현재는 창문 타일. 실제 사진이 들어가면 가장 크게 좋아지는 부분
