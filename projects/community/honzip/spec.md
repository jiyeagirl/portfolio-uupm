프리셋: web

# 혼집 Product Spec

## 1. Overview

혼집은 혼자 사는 20~30대 여성이 같은 동네 사람들과 생활 정보를 묻고 나누는 지역 기반 커뮤니티
웹 서비스다. 집 수리 업체 추천, 밤길 안전, 택배 보관, 동네 병원처럼 혼자 살면서 생기는 질문을
같은 동네 사람에게 묻고, 검증된 답을 다시 찾아볼 수 있게 하는 것이 목적이다.

이 프로젝트는 워크스페이스의 `web` 프리셋을 시험하기 위한 **화면 3개짜리 최소 프로젝트**다.
기능 범위를 넓히지 않는다.

- **플랫폼**: Web (고객용 반응형 사이트). 데스크톱 1440과 모바일 393을 모두 지원한다.
- **사용자**: 가입한 일반 회원 1종류만 다룬다. 관리자 화면은 만들지 않는다.
- **데이터**: 전부 목업 데이터. 로그인은 이미 된 상태로 시작하고, 글쓰기와 공감, 댓글은 화면 안
  컴포넌트 상태로만 처리한다.

## 2. Information Architecture

화면은 3개이고, 상단 내비게이션(모바일은 하단 탭이 아닌 상단 메뉴)으로 오간다. 게시글 상세는
홈의 글 목록에서 글을 눌러 들어간다.

1. **홈** (`home`)
   - 상단: 현재 동네 표시(예: "망원동")와 동네 변경 버튼, 검색창, "글쓰기" 버튼
   - 주제 탭: 전체 / 동네 정보 / 안전 / 집 관리 / 생활 꿀팁 / 같이 해요
   - 이번 주 많이 본 글 3개 (제목, 주제, 공감 수)
   - 최신 글 목록: 주제, 제목, 본문 앞부분, 작성자 닉네임, 동네, 작성 시각, 공감 수, 댓글 수,
     첨부 사진이 있으면 썸네일
   - "해결됨" 표시: 질문 글 중 작성자가 답변을 채택한 글
   - 데스크톱은 우측에 "우리 동네 안전 알림" 박스(최근 3건, 예: "망원역 2번 출구 가로등 고장 신고됨")
2. **게시글 상세** (`post`)
   - 주제, 제목, 작성자 닉네임과 동네, 작성 시각, 본문, 첨부 사진(최대 3장)
   - 공감 버튼과 공감 수, 저장 버튼
   - 질문 글이면 채택된 답변을 댓글 목록 맨 위에 고정하고 "작성자가 채택한 답변" 표시
   - 댓글 목록(닉네임, 동네, 시각, 내용)과 댓글 입력창. 입력하면 목록 맨 아래에 바로 추가된다
   - 데스크톱은 우측에 같은 주제의 다른 글 4개
3. **글쓰기** (`write`)
   - 주제 선택(필수), 글 종류 선택(질문 / 정보 공유), 제목(필수), 본문(필수), 사진 첨부(최대 3장)
   - 동네 공개 범위: 우리 동네만 / 인근 동네까지
   - 닉네임 대신 "익명으로 올리기" 옵션
   - "등록" 버튼을 누르면 홈 최신 글 맨 위에 새 글이 추가되고 홈으로 돌아간다

## 3. Key Focus

- 3개 화면이 목업 데이터 위에서 이어지는 것: 홈에서 글을 열고, 공감하고, 댓글을 달고, 새 글을 써서
  홈에 올라오는 한 바퀴가 돌아야 한다.
- 데스크톱과 모바일 둘 다 자연스러워야 한다. 데스크톱의 우측 박스는 모바일에서 본문 아래로 내려가거나
  접힌다.
- 커뮤니티 특유의 신뢰감: 동네 인증된 이웃이라는 느낌, 해결된 질문이 눈에 띄는 것.
- 여성 대상 서비스라고 해서 분홍색과 하트 일색의 뻔한 표현을 쓰지 않는다. 차분하고 생활감 있는
  톤을 우선한다.

## 4. Mock Data Guide

- 기본 동네: 망원동. 인근 동네는 합정동, 서교동, 성산동.
- 게시글 10~12건. 주제가 골고루 섞이고, 질문 글 중 해결됨이 최소 2건, 사진이 있는 글이 최소 3건.
- 글 예시 주제: 원룸 곰팡이 제거 업체 추천, 밤 11시 이후 망원역에서 집까지 안전한 길, 무인 택배함
  위치, 혼자 가기 좋은 동네 내과, 남는 식재료 소분 나눔, 주말 한강 러닝 같이 할 사람.
- 닉네임은 생활감 있는 가상 닉네임(예: 망원동고양이집사, 성산동새벽러너). 실명, 실제 상호명은 쓰지
  않는다. 업체가 필요하면 "A인테리어", "B내과"처럼 익명화한다.
- 사진은 주제와 맞는 것만 쓴다. 맞는 사진이 없으면 자리만 두고 사진 요청 목록에 적는다.

## 5. Out of Scope

로그인과 회원가입 화면, 동네 인증 절차, 쪽지, 알림 센터, 신고 처리, 관리자 화면, 프로필 페이지,
검색 결과 화면, 다크 모드.
