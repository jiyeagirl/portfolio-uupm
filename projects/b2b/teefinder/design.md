# 디자인 적용
해석: 골프 회원권 회원 전용 빈 티타임 통합 앱(iPhone 16 Pro 프레임 1대)과 운영자 관리자 웹(console) for 골프 회원권 사업자의 회원, 운영자. 다이얼 V7/M6/D5 (앱). 관리자 웹은 console 기준으로 절제.

## 채택 (UUPM)
- 카테고리 Booking & Appointment App: spec의 업종(예약, 슬롯 조회)과 일치. 보조 검색 1순위도 같은 카테고리.
- 스타일 Soft UI Evolution: 그림자 최소, 부드러운 면 구분만 채택. 두꺼운 소프트 그림자는 쓰지 않음.
- 상태 의미: "가능 = 초록, 마감 = 회색" (UUPM 팔레트 포커스).
- 디스플레이 폰트 Poppins (intake가 Inter를 교체): 영문 워드마크와 영문 라벨에만 사용. 숫자는 고정폭 미지원이라 Pretendard tabular-nums.

## 버림
- UUPM primary 파랑과 accent 초록: spec 상태 색(보안인증, 취소티 = 파랑 / 정상, 예약 가능 = 초록)과 겹쳐 브랜드와 상태가 섞임. 브랜드는 다크 그린 ink + 브라스로 교체.
- 랜딩 페이지 섹션 패턴, GSAP, 모달 blur (intake가 이미 버림).
- 회색 테두리 카드 그리드: 카카오골프 실측에서 확인한 방식이고 서비스 고유 인상이 없음.
- 지역 7칸 균등 타일: 같은 이유. 필터는 문장형으로 바꿈.
- 파랑 계열 배경 + 파랑 CTA: 스마트스코어 등 업종 기본색이라 구분이 안 됨.

## 앞선 프로젝트와 다르게 고른 것
- 셸: 앱은 풀블리드 다크 그린 헤더 면 + 4탭 하단바. 관리자는 흰 본문 + ink 좌측 레일 + 승인 화면 마스터 디테일.
- 한글 제목 폰트: Gowun Batang(세리프). 워크스페이스의 다른 프로젝트는 Hahmlet, Wanted/SUIT 계열 또는 Pretendard.
- 본문 15px / 행간 22px, 눌림 피드백은 배경 틴트(scale 없음), 진입 모션 translateY 8px + fade 220ms ease-out.

## 아트 디렉션
무드: 격조 있는, 또렷한, 스코어카드 같은
레퍼런스:
- 카카오골프예약 웹(실측): 사용자가 준 캡처로 확인. 상단 회색 띠 100px 안에 워드마크(앞 3자 가는 굵기, "골프예약" 굵게)와 검색창. 날짜 스트립은 요일 위, 숫자 아래 한 줄이고 선택일은 진한 알약, 일요일 빨강, 토요일 파랑. 카드는 2열이고 시간대 "오전 8시대"를 초록 작은 글자로 좌상단, 상태 칩(모집중, 티타임 미정)은 우상단, 골프장명 굵게, 지역과 별점 한 줄, 가격 굵게. 가져올 것: 날짜 스트립의 요일 위 숫자 아래 구조와 선택일 반전. 반대로 버릴 것: 회색 테두리 카드의 균질함.
- 스마트스코어 앱스토어 캡처(실측): 사용자가 준 캡처로 확인. 화면마다 코랄, 블루 같은 포화 색을 전면에 깔고 큰 디스플레이 글자를 얹음. 날짜와 시간 조건은 표형 행(날짜 전체, 7시 이전, 7-9시 ...)으로 나열. 가져올 것: 화면 상단을 큰 단색 면으로 쓰는 방식(홈 상단 ink 면). 파랑 계열 색은 가져오지 않음.
- 매거진 B(미확인, 기억 기반): 제목은 크고 본문은 아주 작게 해서 크기 대비로 위계를 만들고 여백을 넉넉히 둠. 가져올 것: 큰 시간 숫자와 작은 보조 글자의 크기 대비.
시그니처:
- 큰 색 면적: 홈 상단 약 40%를 ink(#0E2A22) 면으로 깔고 그 안에 인사, 문장형 필터, 날짜 스트립을 흰 글자로 둠. 로그인과 승인 대기 화면도 ink 전면. 화면 3개 중 3개.
- 타이포 대비: 티타임 시간(07:12)을 Pretendard 700 26px tabular-nums로 크게, 골프장명과 코스는 13px로 작게. 한글 제목은 Gowun Batang 700. 홈, 골프장 상세, 알림함에 노출.
- 브랜드 마크: 티(tee) 위에 공이 올라간 형태의 SVG 마크 + "TeeFinder" Poppins 워드마크. 로그인, 홈 헤더, 웹뷰 로딩에 노출.
- 마이크로 인터랙션: 웹뷰 자동 로그인 3단계가 끝나면 공이 컵에 들어가는 체크 애니메이션(1회, 600ms, prefers-reduced-motion이면 정지 상태 체크).

한글 디스플레이: Gowun Batang (고전적인 세리프. 회원권, 클럽하우스 같은 격조 있는 무드. 제목에만 사용)

## 구조 변경
- 홈의 필터를 칩 행에서 문장형으로 바꿈. "이번 토요일, 경기, 15만 원 이하 자리 보기"처럼 날짜, 지역, 가격이 한 문장 안의 밑줄 슬롯이고 누르면 시트가 열림. 지역 균등 타일과 칩 3줄을 대체.
- 골프장 카드를 "티켓" 구조로 바꿈. 좌측에 가장 이른 빈 시간을 큰 숫자로 세우고 우측에 골프장명, 코스, 그린피를 두며, 아래에 나머지 시간 칩을 가로 스크롤로 이어 붙임. 2열 균질 카드를 1열 가변 행으로 교체.
- 취소티는 목록 안 배지가 아니라 홈 최상단 파란 띠(풀폭)로 분리해 올림. 목록과 섞이지 않게 함.

## 더한 것
- ink 전면 헤더 면과 브라스 포인트(회원권 번호, 즐겨찾기 하트): 브랜드 색 면적 확보 (버림의 파랑 교체와 쌍).
- 시간 숫자 중심 티켓 카드 + 가로 스크롤 시간 칩: 회색 카드 그리드를 대체.
- 문장형 필터: 칩 행과 지역 타일을 대체.
- 티와 공 SVG 마크, 컵에 들어가는 완료 애니메이션: 업종 고유의 그림.
- 앱과 관리자가 한 상태를 공유(승인, 반려, 푸시 공지가 양쪽에 즉시 반영): spec 핵심 흐름을 화면에서 확인할 수 있게 함.
